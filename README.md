# ProductAuthenticity

GenLayer Intelligent Contract untuk verifikasi klaim asal-usul/keaslian produk
(supply-chain authenticity) menggunakan AI + web evidence.

- `register_product(product_id, claimed_origin, evidence_url)`
- `verify_authenticity(product_id)` — AI cross-check evidence vs klaim, verdict VERIFIED/REJECTED
- `get_product(product_id)`

Deployed on GenLayer Studio Next (chain 61997).
